# 📖 Glossary

Domain terms used across this repo. One line each. Keep alphabetic.

| Term | Meaning |
|---|---|
| Agent | An AI coding assistant (Copilot, Claude, Gemini, Codex, Cursor, ...). |
| Ainur | The primordial spirits (Valar and Maiar) who shaped the world before its peoples; see [`design-notes-ainur-v2.md`](../design/design-notes-ainur-v2.md). |
| Doctrine | One of Melkor's two mutually exclusive hero kits (Worldbreaker / Dark Architect); locked per campaign. |
| Faction | A playable civilization or order with its own economy and one recreatable hero; 54 exist in revision 6. |
| Field power | A hero's local, encounter-scale signature ability; costs the hero's field-encounter commitment. |
| Hero commitment | The weekly regional-scale assignment a hero spends on a support power instead of travel, combat or recovery. |
| Istari | The five Wizard orders (Gandalf, Saruman, Radagast and the two Blue Wizards) plus their generic counterparts. |
| Maiar | Lesser Ainur — spirits below the Valar in power, including the Istari and Balrogs. |
| Readiness | A hero's resource pool spent on field/support powers; 6 normally, 12 for Melkor's Worldbreaker doctrine. |
| Revision | A numbered iteration of the design report; revision 6 is current, revisions 1-5 are archived under [`docs/design/iterations/`](../design/iterations/). |
| Run | A single agent invocation that may span many tool calls. Identified by `run_id`. |
| Scope | The named slice of work an agent is touching (phase id, module slug, area). |
| Support power | A hero's regional-scale signature ability; costs the weekly hero commitment instead of a field-encounter commitment. |
| Tactical phase | The basic time unit for local encounter resolution; hard disables grant two tactical phases of immunity after ending. |
| Tracking row | One line in `docs/tracking/tracking.csv` recording an agent action. |
| Valar | The fourteen most powerful Ainur; all are individually playable per the current design report. |
