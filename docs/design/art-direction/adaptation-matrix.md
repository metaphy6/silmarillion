# From evidence to Silmarillion design

This matrix records **new art and UX decisions**, not changes to gameplay or
claims about Tolkien's canon. DE IDs resolve through
[research-ledger.json](research-ledger.json); LORE and PROJECT IDs resolve
through [source-authority.md](source-authority.md). The matrix owns the
adaptation rationale. Execution requirements live in the named owner document,
so later tuning updates that document rather than copying a second rule here.

**Adopt** retains a transferable principle. **Transform** changes its form or
purpose for this project. **Reject** prohibits the described transfer without
a separate project decision. Numerical sizes, camera parameters and density
targets in the package are testable proposals, not facts inferred from Disco
Elysium. Faction implementation coverage belongs to the complete
[faction matrix](faction-matrix.md) and [structured treatments](faction-matrix.json).

## Deliberate thematic translation

Revachol's policing, institutions, contemporary ideological terminology,
character likenesses and quoted dialogue are outside this project's visual
vocabulary. The transferable concern is a person living inside material
history. Here that becomes the steward who has outlived a forest, the maker
who must release ownership, a mortal ruler fearing loss, or a witness whose
memory is incomplete. These are **new scene directions**, not newly discovered
Tolkien events or unapproved gameplay systems.

Wonder is allowed to be beautiful. Grief can sit beside ordinary kindness;
humor comes from specificity, care, vanity or mismatched expectations rather
than reflexive cynicism. Oaths, craft, stewardship and costly power must be
grounded in the source class and chronology of the actual scene. Do not infer
that all cultures share one dark stone city, one mourning voice or one magical
glow. LORE-13 contrasts reconciliation, the possessive oath and doubt about
continuing it: an oath is not a universal positive morality score.

## Acceptance boundary

The package can measure source/ID coverage, token contrast, declared image
sizes and static layout behavior. Visual review can judge focal hierarchy,
silhouettes, material identity and whether a composition communicates its
intent. Player comprehension, emotional impact, occlusion during travel,
spatial audio, runtime performance and strategic balance still require
implementation or playtesting. None follows automatically from an attractive
gallery image.
