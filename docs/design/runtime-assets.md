### Software-renderer performance correction

CDP profiling identified software WebGL framebuffer readback as the dominant cost: approximately 20.9ms per frame in `GLES2::ReadPixels`, versus less than 1ms in JavaScript. A temporary, released WebGL probe now selects Phaser Canvas only for explicitly identified SwiftShader, llvmpipe, softpipe or other named software renderers. Hardware and unknown renderers retain Phaser AUTO. This removes the software framebuffer readback without reducing the frame-rate target, image resolution, painted detail or animation. Dynamic textures, alpha, authoritative terrain masks, selection and DOM interactions retain the same implementation and pass browser parity checks.

Regression evidence is explicit about chronology: tests were authored before the helper, but the first execution followed implementation.
