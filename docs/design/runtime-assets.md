Family silhouettes/material cues differ; these are provisional vector graphics, not a painted animation atlas. Movement tweens are cosmetic, use committed state and respect reduced motion. The profile portrait coverage below is a discrete delivered asset set, not completion of those other domains. Reference book/text and gallery/reference artwork remain outside `public/` and `dist/`.
