# Brethil concept view

[brethil-isometric-concept.png](brethil-isometric-concept.png) is an original generated visual-development plate made with the built-in image-generation tool. It illustrates a proposed local crossing, camp, and travel routes; it is not a canonical map, a reproduced book illustration, a game screenshot, or a finished production asset.

The scale relationship is the key decision: small people and everyday objects within a continuous, dominant landscape. Exact pixel sizes, selection readability, and navigation remain prototype tests.

The complete generation prompt is saved in [concept-prompt.txt](concept-prompt.txt).
