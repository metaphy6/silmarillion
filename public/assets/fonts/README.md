# Bundled Noto typography

Unmodified TrueType files copied on 2026-09-30 from the workstation's existing
`/usr/share/fonts/truetype/noto/` installation. No system installation or font
modification was performed. Noto Sans Regular/Bold supplies interface and canvas
labels; Noto Serif Regular/Italic supplies headings and introductory prose.

Copyright 2010, 2012–2020 Google Inc.; 2015–2020 Google LLC. Font files are under
SIL Open Font License 1.1. [LICENSE.txt](LICENSE.txt) preserves the complete
installed Debian copyright notice from `/usr/share/doc/fonts-noto-core/copyright`,
including the upstream grant and full OFL text. Its separate Debian packaging
license concerns packaging, not these font binaries.

Source provenance: https://github.com/googlei18n/noto-fonts (as recorded in that
installed copyright notice). This bundle does not claim to be the latest release.
Exact SHA-256 identities are pinned in `tests/font-assets.test.ts`; these are
third-party licensed production font assets, not generated concept artwork.
Current English interface and roster diacritics are tested; further localization
requires checking its complete character repertoire before release.
